# ملاحظة — الألفاظ النابية والشتائم والإهانات الشخصية
## الألفاظ النابية والشتائم والإهانات الشخصية
article_14
## الهدف
هذه ملاحظة معلوماتية لغرض المراجعة البشرية. لا تمثل قراراً بالمسؤولية أو مخالفة. الهدف هو تقييم ما إذا كان الحدث المهيكل يحتوي على ألفاظ نابية أو شتائم أو إهانات شخصية موجهة إلى شخص محدد، مع الاحتفاظ بالنص الحرفي للدليل.

## تعليمات الكشف
راجع كل حدث مهيكل بشكل مستقل. استخدم فقط ما ورد في الحدث والتفاصيل الحرفية في النص المصدر. لا تحاول بناء تفسير إضافي أو افتراض نية غير موجودة في النص.

### Decision Gates

طبّق البوابات التالية على كل حدث بشكل مستقل. لا تنشئ ملاحظة بسبب كلمة مفتاحية أو صلة بحدث أو مادة أخرى.

#### Gate 1 — Identifiable Target

يجب أن يتضمن الحدث شخصاً أو هدفاً محدداً تتم مخاطبته أو الإشارة إليه أو وصفه فعلاً. إذا لم يوجد هدف قابل للتحديد → **لا تخرج ملاحظة**.

#### Gate 2 — Offensive Language

يجب أن يتضمن الحدث فعلاً لغوياً مسيئاً، مثل لفظ نابي، شتيمة مباشرة، وصفاً مهيناً أو حاطاً، لغة إذلال، عبارة مسيئة بوضوح، أو تعبيراً شخصياً محتقراً. يجب أن يحتوي `quote` على اللغة ذات الصلة كلما أمكن.

#### Gate 3 — Context

يجب أن تعمل العبارة فعلاً كإهانة أو إساءة في سياق الحدث. لا تعتبر الاقتباس المحايد لإهانة، أو مناقشة الألفاظ النابية، أو قراءة مثال تعليمي، أو وصف شرطي لإهانة كدليل، أو الإشارة التاريخية أو الوثائقية أو التحليلية، أو الكلام العامي العادي، أو الاختصار غير المهين، أو الخطأ الإملائي ملاحظة تلقائياً.

إذا لم تثبت البوابات الثلاث معاً → **لا تخرج ملاحظة**.

### مؤشرات الملاحظة
- الشتائم الصريحة أو الألفاظ النابية.
- الإهانات الشخصية أو التحقير أو السخرية المهينة.
- التهديد أو القذف فقط عندما يكون مهيناً أو مسيئاً فعلاً ضمن نطاق المادة.
- لغة عامية أو كسر إملائي واضح معناه الإهانة أو الاحتقار.

## قواعد مهمة
- هذه الملاحظة ليست قراراً بوجود مخالفة؛ هي ملاحظة للمراجعة البشرية.
- استخدم `quote` فقط كدليل حرفي من الحدث.
- لا تعتمد على الاستنتاجات أو التفسيرات غير الموثقة.
- إذا ظهر أكثر من حدث مستقل، أخرج ملاحظة منفصلة لكل حدث.
- احتفظ بـ `event_id` و `quote` بدقة كاملة.
- إذا لم تجد أي إشارة كافية، أخرج `{"notes": []}`.

### Hard Negatives and Independence

لا تعتبر المعلومات المضللة، أو التسجيلات المزيفة، أو الاتهامات السياسية أو اتهامات الفساد، أو نقد الحكومة، أو التهديد بلا لغة مهينة، أو «كله كذب»، أو «معلومات مضللة»، أو «حسابات وهمية» مرشحاً للمادة (14) تلقائياً.

«تهديد» وحدها لا تساوي شتيمة، و«اتهام» وحدها لا يساوي إهانة شخصية، و«كذب» قد يكون أو لا يكون إهانة بحسب الهدف والسياق. الادعاء الواقعي والخلاف السياسي ليسا إهانة تلقائياً.

قد يكون الحدث الواحد مرشحاً لأكثر من مادة، لكن يجب تحقق موضوع/هدف المادة (14) والسلوك الخاص بها والدليل الحرفي بصورة مستقلة. لا تنقل الصلة من حدث آخر أو من سياق سابق؛ السياق يوضح الإحالة ولا يصنع إهانة غائبة. المعرفة الخارجية لا تنشئ الصلة.

### Regression Guidance

`حسابات وهمية، تسجيلات مزيفة، معلومات مضللة.` → لا تطابق: لا توجد شتيمة أو إهانة شخصية.

`هذا كذب.` → لا تطابق تلقائياً: لا تستخدم الكلمة وحدها دون هدف وسياق.

`يا حمارة`، `يا فاشل`، `عديم التربية` → مرشح محتمل عندما تكون موجهة بوضوح إلى شخص في سياق مهين أو حاط.

# Output Contract (MANDATORY)

أعد JSON صالحاً فقط، دون أي نص أو Markdown خارج كائن JSON واحد:

```json
{
	"notes": [
		{
			"category": "article_14",
			"title": "",
			"description": "",
			"paragraph": "",
			"quote": "",
			"event_id": 12,
			"confidence": 0.7
		}
	]
}
```

- category: يجب أن تكون `article_14`.
- title: عنوان قصير وواضح للملاحظة.
- description: وصف الملاحظة للمراجع البشري.
- paragraph: السياق المحيط بالحدث من النص الأصلي.
- quote: اقتباس حرفي قصير، ويجب أن يكون جزءاً مطابقاً حرفياً من الحدث المقدم.
- event_id: رقم حدث موجود فعلياً في StructuredEvents المقدمة.
- confidence: قيمة رقمية بين 0 و 1.

إذا تعذر إنتاج أي حقل إلزامي، فلا تُخرج تلك الملاحظة. إذا لم توجد إشارة كافية، أعد `{"notes": []}`.
