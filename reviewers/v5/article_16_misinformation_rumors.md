# Decision Principle

لكل حدث طبّق البوابات التالية بالترتيب. لا تحول كل ادعاء غير متحقق منه إلى معلومات مضللة.

## Gate 1 — Actual Claim

يجب أن يتضمن الحدث نفسه ادعاءً أو تقريراً أو اتهاماً أو معلومة قابلة للتحديد. مجرد ذكر خبر أو إشاعة أو منشور أو تغريدة أو رسالة أو مصدر أو فيديو لا يكفي.

## Gate 2 — Adoption/Transmission

يجب أن يظهر في الحدث أن شخصاً ينشر أو يكرر أو يروج أو يتداول أو يعرض المعلومة كحقيقة أو يتبناها أو ينقلها. قول «هناك إشاعة عن...» وحده لا يثبت نشر معلومات مضللة.

## Gate 3 — Misleading Signal

يجب أن يتضمن الحدث إشارة ملموسة إلى التضليل أو الكذب، مثل الاعتراف بالاختلاق، أو التصريح بعدم وجود دليل مع عرض المعلومة كحقيقة، أو الاختلاق المتعمد أو التلاعب أو التزييف أو تناقض داخلي يثبت الخطأ.

إذا لم توجد إشارة ملموسة فلا تخترع الكذب. وإذا تعذر إثبات الحقيقة نهائياً، فلا تخرج ملاحظة إلا إذا قدم الحدث نفسه سبباً خاصاً بالمادة للمراجعة البشرية.

## Gate 4 — Exact Evidence

يجب أن يثبت `quote` حرفياً الادعاء، وتبنيه أو نقله، وإشارة التضليل معاً.

## Hard Negatives

لا تخرج ملاحظة لمجرد خبر أو إشاعة مذكورة أو سؤال عن إشاعة أو رسالة أو تغريدة أو مصدر أو تغطية إعلامية أو صحافة خيالية أو اتهام أو رأي أو سخرية أو محتوى تاريخي أو وثائقي.

لا تنقل الصلة من حدث آخر أو مادة أخرى، ولا تعتمد على معرفة خارجية لإنشاء كذب غائب. المراجعة البشرية تبرر إنشاء ملاحظة فقط بعد تحقق الصلة الموضوعية والسلوكية بالمادة.

## Regression Guidance

`حسام: سمعت إشاعة أن هناك قراراً جديداً.` → لا تطابق: مجرد ذكر إشاعة بلا تبنٍ أو إثبات تضليل.

`فهد: بنركب قصة عن فساد ما صار ونخلي الناس تصدقها.` → مرشح محتمل: اختلاق متعمد مع دفع الناس إلى التصديق.
