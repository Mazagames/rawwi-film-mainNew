# Decision Principle

لكل حدث طبّق البوابات التالية بالترتيب. لا تكفي الكلمات المرتبطة بالسحر أو الخرافة وحدها.

## Gate 1 — Supernatural Practice

يجب أن يتضمن الحدث نفسه ممارسة أو تعليماً أو ترويجاً أو تأييداً للسحر أو الشعوذة أو التنجيم أو قراءة الطالع أو ادعاء معرفة الغيب أو التعامل مع الجن أو الشياطين.

إذا لم توجد ممارسة أو دعوة أو ادعاء محدد → **لا تخرج ملاحظة**.

## Gate 2 — Reality/Endorsement

يجب أن يقدم الحدث هذه الممارسة باعتبارها حقيقية أو فعالة أو قابلة للاستخدام أو قادرة على إنتاج نتائج واقعية أو شيئاً ينبغي للناس فعله. السرد الخيالي أو الفانتازي لا يكفي تلقائياً.

## Gate 3 — Exact Evidence

يجب أن يثبت `quote` حرفياً الممارسة الخارقة وتقديمها كحقيقية أو مؤيدة. لا تنقل الصلة من حدث أو مادة أخرى، ولا تستخدم المعرفة الخارجية لإنشاء تأييد غائب.

## Hard Negatives

لا تخرج ملاحظة لمجرد كلمات «سحر» أو «جن» أو «شيطان» أو الأبراج أو الراقي أو الشيخ أو التمائم أو الطلاسم، أو ذكر التنجيم في نقاش، أو ساحر خيالي أو تعويذة فانتازية، أو محتوى تاريخي أو وثائقي أو تعليمي أو تحذير ديني أو كشف خداع مشعوذ.

## Regression Guidance

عمل فانتازي يتضمن ساحراً أو تعويذة → لا يطابق تلقائياً.

`اذهب لهذا المشعوذ، سيستحضر الجن فعلاً ويجعلهم ينفذون ما تريد.` → مرشح محتمل: ممارسة خارقة مقدمة كحقيقية وقابلة للتنفيذ.
