# Decision Principle

لكل حدث طبّق البوابات التالية بالترتيب. لا تكفي مناقشة الاقتصاد أو المال وحدها.

## Gate 1 — Economic/Financial Subject

يجب أن يتضمن الحدث نفسه ادعاءً اقتصادياً أو مالياً، أو مسألة بنك أو مؤسسة مالية أو سوق أو عملة أو استثمار أو استقرار اقتصادي أو ذعراً مالياً أو ضرراً بالاقتصاد الوطني.

إذا لم يوجد موضوع اقتصادي أو مالي محدد → **لا تخرج ملاحظة**.

## Gate 2 — Concrete Harmful Conduct

يجب أن يتضمن الحدث نشر معلومات مالية مضللة، أو إشاعة مالية متعمدة، أو إنشاء ذعر مالي، أو دعوة غير مؤسسة لسحب الأموال، أو محاولة متعمدة للإضرار ببنك أو سوق أو العملة أو الاستقرار الاقتصادي.

## Gate 3 — Exact Evidence

يجب أن يثبت `quote` حرفياً الموضوع الاقتصادي والسلوك الضار أو المضلل معاً. لا تحول التوقع أو الرأي أو التحليل إلى تضليل تلقائياً. ذكر كلمة "اقتصاد" أو "مال" بمفردها لا يكفي.

## Hard Negatives

لا تخرج ملاحظة لمجرد ذكر الاقتصاد أو البنوك أو الأسواق أو الاستثمار أو الأسهم أو النفط أو سعر الصرف أو العملات أو التضخم، أو خبر مالي طبيعي، أو تحليل سوق، أو نزاع مالي عادي، أو الإبلاغ عن أزمة اقتصادية.

التحقق الخارجي لا يبرر إخراج كل تصريح غير متحقق منه؛ يمكن استخدامه فقط بعد ثبوت مرشح خاص بالمادة في الحدث الحالي. لا تنقل الصلة من حدث أو مادة أخرى، والمعرفة الخارجية لا تنشئ ادعاءً مالياً أو كذباً أو ذعراً أو ضرراً غائباً.

## Explicit False Positives

- ذكر "الاقتصاد" أو "البنك" داخل حدث سياسي عام لا يكفي؛ يجب أن يكون الحدث نفسه يثبت تضليلاً أو ذعراً أو ضرراً مالياً.
- وصف اقتصادي عام أو خبر اقتصادي عادي لا يحقق المادة.
- احتمال تأثير اقتصادي لاحق أو "قد يؤثر على الاقتصاد" لا يكفي.
- مضمون سياسي أو ديني أو إعلامي لا يصبح مالياً فقط لأن فيه كلمة اقتصاد أو بنك.

## Regression Guidance

`سعر النفط نزل اليوم ونحتاج نعيد حساباتنا.` → لا تطابق: نقاش اقتصادي بلا تضليل أو تلاعب ضار.

`انشروا كذبة أن البنك سينهار حتى يسحب الناس أموالهم ونسبب له أزمة.` → مرشح محتمل: تضليل مالي وذعر وضرر متعمد.
