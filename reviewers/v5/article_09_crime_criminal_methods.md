# Decision Principle

لكل حدث طبّق البوابات التالية بالترتيب. وجود جريمة لا يساوي تعليم طريقة ارتكابها أو تسهيلها.

## Gate 1 — Specific Criminal Method

يجب أن يتضمن الحدث نفسه طريقة أو عملية أو تقنية أو إجراءً إجرامياً محدداً، أو تعليمات تشغيلية ملموسة.

إذا لم توجد طريقة إجرامية محددة → **لا تخرج ملاحظة**.

## Gate 2 — Teaching/Facilitation

يجب أن يشرح الحدث أو يوضح أو يعلم أو يشجع أو يسهل مادياً استخدام الطريقة الإجرامية، مثل شرح خطوة بخطوة، أو إرشادات إجرائية، أو تقنية محددة للتنفيذ، أو طريقة لتجنب الكشف أثناء ارتكاب الجريمة بما يسهلها فعلياً.

## Gate 3 — Exact Evidence

يجب أن يثبت `quote` حرفياً الطريقة الإجرامية والسلوك التعليمي أو التسهيل معاً.

## Hard Negatives

لا تخرج ملاحظة لمجرد وقوع جريمة، أو وجود مجرم، أو تحقيق أو توقيف أو محاكمة أو جمع أدلة أو عملية أمنية، أو ذكر السرقة أو الاحتيال أو الاختراق أو التهريب، أو حذف الأدلة أو إخفائها، أو حسابات وهمية أو كذب أو تهديد، أو مناقشة جريمة أو اعتراف شخصية أو وصف شرطي للجريمة.

`احذفوا الأدلة` وحدها ليست مرشحاً للمادة (09). أما شرح تشغيلي محدد مثل: `استخدموا التقنية X ثم نفذوا الخطوة Y لتجاوز نظام الكشف` فهو مختلف لأنه يسهل الجريمة مادياً.

لا تنقل الصلة من حدث آخر أو من مادة أخرى. المعرفة الخارجية لا تنشئ طريقة إجرامية غائبة، والمراجعة البشرية تبرر إنشاء ملاحظة فقط بعد تحقق الصلة الموضوعية والسلوكية بالمادة.

## Regression Guidance

`احذفوا كل شيء… واحرقوا الحسابات.` → لا تطابق: تعليمات بلا طريقة إجرامية محددة.

شرح تشغيلي ملموس لكيفية تنفيذ جريمة أو تجاوز الكشف بطريقة تسهلها مادياً → مرشح محتمل.
