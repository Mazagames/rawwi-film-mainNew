# ملاحظة — العنف والقتل والتعذيب والتمثيل بالجثث
## العنف والقتل والتعذيب والتمثيل بالجثث
article_05
## الهدف
هذه ملاحظة معلوماتية لغرض المراجعة البشرية. لا تشكّل قراراً قانونياً أو تدبيراً تأديبياً أو حكمًا بوجود مخالفة. المهمة هي تقييم الأحداث المهيكلة (StructuredEvents) وتوثيق ما إذا كانت فيها مؤشرات عنف شديد أو قتل أو تعذيب أو تمثيل بالجثث، مع الاحتفاظ بنسخة حرفية من الدليل داخل كل حدث.

## تعليمات الكشف
قِم بتقييم كل حدث من الأحداث المهيكلة بشكل مستقل. استخدم الحدث فقط كأصل للحقيقة. لا تحاول بناء أحداث جديدة أو إعادة تفسير السياق خارج ما ورد في الحدث نفسه.

### مؤشرات الملاحظة
- القتل الوحشي أو التصفية أو الذبح أو تقطيع الجثة.
- التعذيب الجسدي أو النفسي الشديد.
- التمثيل بالجثث أو حرقها أو إذابة جثة أو إخفاءها بعد الجريمة.
- التحريض الصريح أو التمجيد أو التعليم على القتل أو التعذيب.
- أوامر مباشرة بقتل الضحية أو إيذائها أو التخلص منها.
- السياق الذي يوضح أن العنف أو القتل أو التعذيب هو العنصر الرئيسي في الحدث.

## قواعد مهمة
- هذه الملاحظة ليست قراراً بوجود مخالفة؛ هي ملاحظة للمراجعة البشرية.
- استخدم فقط `quote` داخل الحدث كدليل حرفي.
- لا تعتمد على التخمين أو التفسير غير الموثق.
- لا تخلط بين الحادث العادي والقتل أو التعذيب أو التمثيل بالجثث الواضح.
- احتفظ بـ `event_id` كما هو، واحتفظ بالأقواس/النصوص الحرفية من الحدث.
- إذا كان هناك أكثر من حدث مستقل، أخرج ملاحظة مستقلة لكل حدث.
- إذا لم يكن هناك دليل كافٍ، أخرج ملاحظة فارغة.

# Output Contract (MANDATORY)

أعد JSON صالحاً فقط، دون أي نص أو Markdown خارج كائن JSON واحد:

```json
{
	"notes": [
		{
			"category": "article_05",
			"title": "",
			"description": "",
			"paragraph": "",
			"quote": "",
			"event_id": 12,
			"confidence": 0.7
		}
	]
}
```

- category: يجب أن تكون `article_05`.
- title: عنوان قصير وواضح للملاحظة.
- description: وصف الملاحظة للمراجع البشري.
- paragraph: السياق المحيط بالحدث من النص الأصلي.
- quote: اقتباس حرفي قصير، ويجب أن يكون جزءاً مطابقاً حرفياً من الحدث المقدم.
- event_id: رقم حدث موجود فعلياً في StructuredEvents المقدمة.
- confidence: قيمة رقمية بين 0 و 1.

إذا تعذر إنتاج أي حقل إلزامي، فلا تُخرج تلك الملاحظة. إذا لم يوجد دليل كافٍ، أعد `{"notes": []}`.
