# ملاحظة — العنف والقتل والتعذيب والتمثيل بالجثث
## العنف والقتل والتعذيب والتمثيل بالجثث
article_05
## الهدف
هذه ملاحظة معلوماتية لغرض المراجعة البشرية. لا تشكّل قراراً قانونياً أو تدبيراً تأديبياً أو حكمًا بوجود مخالفة. المهمة هي تقييم الأحداث المهيكلة (StructuredEvents) وتوثيق ما إذا كانت فيها مؤشرات عنف شديد أو قتل أو تعذيب أو تمثيل بالجثث، مع الاحتفاظ بنسخة حرفية من الدليل داخل كل حدث.

## تعليمات الكشف
قِم بتقييم كل حدث من الأحداث المهيكلة بشكل مستقل. استخدم الحدث فقط كأصل للحقيقة. لا تحاول بناء أحداث جديدة أو إعادة تفسير السياق خارج ما ورد في الحدث نفسه.

### مؤشرات الملاحظة
- القتل الوحشي أو التصفية أو الذبح أو تقطيع الجثة.
- التعذيب الجسدي أو النفسي الشديد.
- التمثيل بالجثث أو حرقها أو إذابة جثة أو تقطيعها أو تدنيسها بعد الوفاة.
- التحريض الصريح أو التمجيد أو التعليم على القتل أو التعذيب.
- أوامر مباشرة بقتل الضحية أو إيذائها أو التخلص منها.
- السياق الذي يوضح أن العنف أو القتل أو التعذيب هو العنصر الرئيسي في الحدث.

### Decision Gates

قيّم كل حدث بشكل مستقل. استخرج جميع الأحداث التي تستوفي شروط الصلة الخاصة بالمادة، دون إسقاط أي حدث مؤهل. إذا كان الحدث مرتبطاً بمادة أخرى لكنه لا يستوفي شروط المادة (05) بشكل مستقل، فلا تخرجه للمادة (05).

#### Gate 1 — Severe Violence/Killing/Torture Subject

يجب أن يتضمن الحدث نفسه دليلاً على قتل، أو محاولة قتل حيث تكون ذات صلة، أو عنف جسدي شديد، أو تعذيب جسدي أو نفسي شديد، أو تمثيل/تدنيس جثة، أو أمراً صريحاً بالقتل أو الإيذاء الشديد.

إذا لم يوجد هذا الموضوع → **لا تخرج ملاحظة**.

#### Gate 2 — Exact Type of Conduct

حدد ما يثبته الحدث فعلاً، ولا ترفع مستوى الخطورة بما يتجاوز الدليل: الصراع العادي لا يساوي قتلاً، والتهديد لا يساوي قتلاً فعلياً، والجدال لا يساوي عنفاً شديداً، والإصابة لا تساوي تعذيباً، وذكر الوفاة لا يساوي جريمة قتل.

التعذيب يتطلب إساءة جسدية أو نفسية شديدة ومتعمدة بقصد التعذيب، لا مجرد ألم أو إصابة. والتمثيل بالجثث يتطلب دليلاً فعلياً على التقطيع أو التفكيك أو الحرق أو الإذابة أو التدنيس بعد الوفاة؛ إخفاء الجثة وحده لا يكفي.

#### Gate 3 — Exact Evidence

يجب أن يثبت `quote` حرفياً نوع العنف أو القتل أو التعذيب أو التمثيل والسلوك ذي الصلة. لا تنقل الصلة من حدث أو مادة أخرى، ولا تستخدم المعرفة الخارجية لإنشاء شدة أو فعل غائب.

### Hard Negatives

لا تخرج ملاحظة لمجرد الصراخ أو الجدال أو التهديد وحده أو اللمس البسيط أو الصفعة غير الشديدة أو الدفع أو الشجار العادي أو إصابة بلا عنف شديد أو اعتقال الشرطة أو وجود سلاح أو تحقيق قتل أو مناقشة قتل سابق أو خبر جريمة أو علاج طبي بعد العنف.

### Regression Guidance

`تشاجر الاثنان ودفع أحدهما الآخر.` → لا تطابق: صراع جسدي عادي غير كافٍ.

`أمسك به وربطه ثم عذبه لساعات باستخدام أدوات مختلفة.` → مرشح محتمل: فعل تعذيب صريح.

## قواعد مهمة
- هذه الملاحظة ليست قراراً بوجود مخالفة؛ هي ملاحظة للمراجعة البشرية.
- استخدم فقط `quote` داخل الحدث كدليل حرفي.
- لا تعتمد على التخمين أو التفسير غير الموثق.
- لا تخلط بين الحادث العادي والقتل أو التعذيب أو التمثيل بالجثث الواضح.
- احتفظ بـ `event_id` كما هو، واحتفظ بالأقواس/النصوص الحرفية من الحدث.
- إذا كان هناك أكثر من حدث مستقل، أخرج ملاحظة مستقلة لكل حدث.
- إذا لم يكن هناك دليل كافٍ، أخرج ملاحظة فارغة.

قد يكون الحدث مرتبطاً بأكثر من مادة، لكن يجب إثبات موضوع المادة (05) وسلوكها والدليل الحرفي بشكل مستقل. السياق يوضح الإحالات ولا يصنع دليلاً غائباً. هذه ملاحظة للمراجعة البشرية وليست حكماً بمخالفة.

# Output Contract (MANDATORY)

أعد JSON صالحاً فقط، دون أي نص أو Markdown خارج كائن JSON واحد:

```json
{
	"notes": [
		{
			"category": "article_05",
			"title": "",
			"description": "",
			"paragraph": "",
			"quote": "",
			"event_id": 12,
			"confidence": 0.7
		}
	]
}
```

- category: يجب أن تكون `article_05`.
- title: عنوان قصير وواضح للملاحظة.
- description: وصف الملاحظة للمراجع البشري.
- paragraph: السياق المحيط بالحدث من النص الأصلي.
- quote: اقتباس حرفي قصير، ويجب أن يكون جزءاً مطابقاً حرفياً من الحدث المقدم.
- event_id: رقم حدث موجود فعلياً في StructuredEvents المقدمة.
- confidence: قيمة رقمية بين 0 و 1.

إذا تعذر إنتاج أي حقل إلزامي، فلا تُخرج تلك الملاحظة. إذا لم يوجد دليل كافٍ، أعد `{"notes": []}`.
