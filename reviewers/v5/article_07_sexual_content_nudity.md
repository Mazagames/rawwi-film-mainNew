# Decision Principle

لكل حدث طبّق البوابات التالية بالترتيب. لا تكفي كلمة جنسية أو إشارة إلى جزء من الجسد.

## Gate 1 — Sexual Subject

يجب أن يتضمن الحدث نفسه موضوعاً جنسياً حقيقياً أو عرياً ذا صلة بالمادة (07).

إذا لم يوجد موضوع جنسي فعلي → **لا تخرج ملاحظة**.

## Gate 2 — Sexual Conduct/Depiction

يجب أن يتضمن الحدث سلوكاً أو تصويراً جنسياً فعلياً، أو طلباً أو عرضاً أو تحريضاً جنسياً صريحاً، أو إيحاءً جنسياً واضحاً، أو عرياً ذا صلة.

## Gate 3 — Exact Evidence

يجب أن يثبت `quote` حرفياً الموضوع والسلوك أو التصوير الجنسي. لا تفسر اللغة الغامضة جنسياً إلا إذا كان الحدث نفسه يوضح معناها.

## Hard Negatives

لا تخرج ملاحظة لمجرد مصطلح تشريحي أو طبي، أو وصف غير جنسي للجسد، أو فحص أو تقرير طبي أو قانوني، أو تحقيق جنائي، أو اعتداء جنسي موصوف محايداً، أو كلمة جنسية مستخدمة كشتيمة، أو استعارة أو عامية بلا معنى جنسي فعلي، أو محتوى تاريخي أو وثائقي أو تعليمي أو طبي غير مُجنّس.

لا تنقل الصلة من حدث أو مادة أخرى، ولا تستخدم المعرفة الخارجية لإنشاء سلوك جنسي غائب. المراجعة البشرية تبرر إنشاء ملاحظة فقط بعد تحقق الصلة الموضوعية والسلوكية بالمادة.

## Regression Guidance

وجود مصطلح تشريحي في فحص طبي أو كلمة جنسية كشتيمة → لا يطابق تلقائياً.

وصف ممارسة جنسية صريحة أو طلب جنسي واضح أو عري ذي صلة → مرشح محتمل.
