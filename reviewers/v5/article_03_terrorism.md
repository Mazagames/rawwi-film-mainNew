# Decision Principle

لكل حدث طبّق البوابات التالية بالترتيب. لا تحول تقييم الإرهاب إلى كاشف عام للعنف أو الأمن أو الفوضى.

## Gate 1 — Terrorism/Extremism Subject

يجب أن يتضمن الحدث نفسه عنصراً ملموساً من عناصر الإرهاب أو التطرف، مثل جماعة إرهابية، نشاط إرهابي، فكر متطرف، هدف إرهابي صريح، تبرير متطرف للعنف، تجنيد، دعم أو تمويل أو دعاية للإرهاب، أو فعل أو خطة إرهابية صريحة.

إذا لم يوجد عنصر إرهاب أو تطرف → **لا تخرج ملاحظة**.

## Gate 2 — Support/Promotion/Incitement

يجب أن يدعم الحدث أو يمجد أو يبرر أو يروج أو يجند أو يسهل أو يشجع أو يحرض لصالح عنصر الإرهاب أو التطرف الموجود.

إذا كان الحدث ينقل أو يحقق أو يدين أو يصف تاريخياً أو يوثق حدثاً إرهابياً دون تبنٍ → **لا تخرج ملاحظة**.

## Gate 3 — Exact Evidence

يجب أن يثبت `quote` حرفياً عنصر الإرهاب أو التطرف والسلوك المؤيد أو المحرض معاً.

## Hard Negatives

لا تخرج ملاحظة لمجرد احتجاج سياسي، أو فوضى مدنية، أو شغب، أو اضطراب عام، أو عداء للحكومة، أو حسابات وهمية، أو إشاعات، أو تضليل، أو تهديد بلا عنصر إرهاب أو تطرف، أو جريمة عادية، أو سلاح بلا سياق متطرف، أو تحقيق أو استجواب أو حادث أمني.

كلمات مثل «الفوضى» أو «التحريض» أو «الشارع» أو «التهديد» أو «العنف» لا تثبت الإرهاب تلقائياً.

لا تنقل الصلة من حدث آخر أو من مادة أخرى. المعرفة الخارجية قد تساعد في فهم عنصر إرهابي موجود، لكنها لا تنشئه. والمراجعة البشرية تبرر إنشاء ملاحظة فقط بعد تحقق الصلة الموضوعية والسلوكية بالمادة.

## Regression Guidance

`حسابات وهمية، تسجيلات مزيفة، معلومات مضللة، ومحاولات للتأثير على الناس.` → لا تطابق: لا يوجد عنصر إرهاب أو تطرف.

`فيه تحريض… وفيه تهديد للأمن العام.` → لا تطابق: تحريض أو تهديد عام لا يثبت الإرهاب.

المدح أو الدعم أو التجنيد الصريح لجماعة إرهابية أو التشجيع الصريح على فعل إرهابي → مرشح محتمل.
