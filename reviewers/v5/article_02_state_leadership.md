# Decision Principle

لكل حدث طبّق البوابات التالية بالترتيب. لا تكفي الصلة الموضوعية أو الكلمات المفتاحية وحدها.

## Gate 1 — Protected Target

يجب أن يحدد الحدث نفسه هدفاً محمياً بالمادة (02): القيادة السياسية، الملك، ولي العهد، أحد أفراد الأسرة المالكة، الحكومة، مؤسسة أو جهة حكومية، أو رمز من رموز السيادة الوطنية.

إذا لم يوجد هدف محمي → **لا تخرج ملاحظة**.

## Gate 2 — Article-Specific Conduct

يجب أن يتضمن الحدث سلوكاً موجهاً إلى ذلك الهدف، مثل الإساءة المباشرة، أو اللغة المهينة، أو المعاملة الحاطة، أو الهجوم العدائي الصريح، أو التحريض ضده، أو الدعوة الصريحة إلى زعزعة نظام الدولة أو إسقاط نظام الحكم حيث يكون ذلك موجوداً فعلاً في الحدث.

الغضب العام، أو الخلاف السياسي، أو النقد الموضوعي لا يكفي.

إذا لم يوجد السلوك الخاص بالمادة → **لا تخرج ملاحظة**.

## Gate 3 — Exact Evidence

يجب أن يكون `quote` اقتباساً حرفياً من الحدث يثبت الهدف المحمي والسلوك معاً. ذكر الملك أو الحكومة أو وزارة فقط لا يكفي.

## Hard Negatives

لا تخرج ملاحظة لمجرد ذكر الملك أو ولي العهد أو الأمير أو الحكومة أو الوزارة أو جهة حكومية، أو وصف قرار حكومي، أو نقد سياسي أو تاريخي أو إخباري أو أكاديمي أو وثائقي، أو مناقشة محكمة أو شرطة، أو غضب أو احتجاج أو اضطراب اجتماعي عام.

كما أن الفوضى العامة، أو حملة التضليل، أو الحسابات الوهمية، أو الإساءة إلى موظف حكومي لا تعني تلقائياً الإساءة إلى القيادة السياسية أو رموز السيادة.

لا تنقل صلة المادة من حدث آخر أو من مادة أخرى. إذا احتاج الحكم إلى معرفة خارجية، فتُستخدم للتحقق بعد ثبوت الصلة، ولا تنشئها.

المراجعة البشرية تبرر إنشاء ملاحظة فقط بعد تحقق الصلة الموضوعية والسلوكية بالمادة.

## Regression Guidance

`وزارة الداخلية داخلة في الموضوع.` → لا تطابق: جهة حكومية مذكورة بلا إساءة أو هجوم خاص بالمادة.

`جهة رسمية؟! كلهم حرامية في الجهات الرسمية حقتكم…` → مرشح محتمل: لغة تحقيرية موجهة إلى الجهات الرسمية، والاقتباس يوفر الدليل.
