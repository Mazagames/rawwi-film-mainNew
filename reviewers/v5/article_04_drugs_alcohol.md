# Decision Principle

لكل حدث طبّق البوابات التالية بالترتيب. لا تكفي الإشارة إلى مادة أو منتج وحدها.

## Gate 1 — Protected Substance/Product

يجب أن يتضمن الحدث نفسه مخدرات أو مواد مسكرة أو كحولاً، أو سجائر أو سيجاراً أو تبغاً أو نيكوتين/منتجاً تبغياً، أو تدخيناً.

إذا لم يوجد المنتج أو السلوك المحمي → **لا تخرج ملاحظة**.

## Gate 2 — Relevant Conduct

بالنسبة للمخدرات والكحول: الترويج أو التشجيع أو التمجيد أو التعليم أو التسهيل أو الاتجار أو التصنيع أو التوزيع أو البيع أو الإخفاء أو التهرب.

وبالنسبة للتبغ والتدخين: الإعلان أو الترويج أو التشجيع أو التمجيد أو الإقناع بالتدخين أو تقديمه كشيء مرغوب أو آمن أو اجتماعي مفيد، أو توزيع المنتجات والترويج لها للقُصّر.

يجب أن يكون السلوك صريحاً وموجوداً في الحدث. تصوير التدخين أو شرب الكحول أو تعاطي المخدرات لا يساوي تلقائياً ترويجاً.

## Gate 3 — Exact Evidence

يجب أن يثبت `quote` حرفياً المنتج أو السلوك المحمي والفعل الترويجي أو الإجرامي ذي الصلة معاً.

## Hard Negatives

لا تخرج ملاحظة لمجرد حمل سيجارة أو تدخين شخصية أو ظهور سيجار أو كحول، أو ذكر المخدرات، أو مصادرة الشرطة لها، أو مناقشة الطبيب للإدمان، أو محتوى وثائقي عن التدخين، أو قول إن الشخصية كانت تدخن.

لا تفترض أن الشخص قاصر إلا إذا أثبت StructuredEvent ذلك. ولا تنقل الصلة من حدث أو مادة أخرى. المراجعة البشرية تبرر إنشاء ملاحظة فقط بعد تحقق الصلة الموضوعية والسلوكية بالمادة.

## Regression Guidance

`فهد يدخن سيجارة وهو جالس.` → لا تطابق: تصوير للتدخين بلا ترويج.

`تعال جرّب السيجارة، صدقني بتصير رجال.` → مرشح محتمل: تشجيع صريح على التدخين.

`وزعوا السجائر على الطلاب الصغار وخلوهم يصورون الإعلان.` → مرشح محتمل: ترويج للتبغ يستهدف القُصّر.
